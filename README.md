# project-gate-recomp
SteinsGate Xbox 360 PC recompilation using ReXGlue

## What is this?
* A minor followup to [project-eleven](https://github.com/ThePlayer14/project-eleven-recomp), since both share a similar codebase. For this reason, the building / troubleshooting instructions are basically the same.
* However, this one's not yet been extensively tested, but it does boot into start screen and successfully starts a new game.
